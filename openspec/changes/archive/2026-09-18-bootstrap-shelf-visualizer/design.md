## Context

См. `proposal.md` (зачем) и `openspec/project.md` (координаты, параметры, окклюдеры). Репозиторий пустой: нет `src/`, нет lockfile. v1 — один статический клиент.

## Goals / Non-Goals

**Goals:**

- Разделить ядро (`src/geometry`), отрисовку (`src/viz`), контролы/URL (`src/ui`, `src/state`) и хостинг (`Dockerfile`, `nginx`, compose).
- Считать блик чистыми функциями; React только отображает результат.
- Дать воспроизводимый toolchain: Node 22, Vite, TypeScript, React, Vitest, nginx:alpine.

**Non-Goals:**

- Фотометрия, IES, PPFD, полноценный 3D как SoT.
- Сервер состояния, аккаунты, аналитика.
- Выбор конкретного CDN/хостера в этом change.

## Decisions

### 1. Стек Vite + TypeScript + React, не FastAPI

Расчёт интерактивный (ползунки), сервер не добавляет ценности. Альтернатива FastAPI + шаблоны отброшена: лишний процесс и деплой. Vanilla TS без React возможен, но слайдеры+URL проще в React.

### 2. Геометрия только в `src/geometry`

Модули: сборка сцены и отрезка ленты; тест отрезок–полигон; выборка ≥16 внутренних точек + концы; `{ hasDirectGlare, samples[] }`. Компоненты не дублируют формулы. Альтернатива «считать в SVG» отвергнута: нельзя честно тестировать без DOM.

### 3. Система координат и лента

Как в `project.md`: origin = стена × верх нижней полки; +X в комнату; +Y вверх; мм.

- `corner`: отрезок от угла (с `profileDrop`) вдоль `emitAngle` (по умолчанию 45°) длиной `led.width`.
- `downward`: горизонтальный отрезок от `offsetFromWall`, длина `led.width`, не дальше `upper.depth`.

Окклюдеры — прямоугольники (полки, бленда). Касание кромки = блок. Альтернатива «одна worst-case точка» отвергнута: внутренний край ленты может бликовать при взгляде снизу.

### 4. Состояние в query string

Один сериализуемый объект параметров ↔ `URLSearchParams`. Без backend. Альтернатива localStorage не даёт шаринг ссылки.

### 5. SVG, не Canvas и не 3D

Разрез, подписи, лучи — декларативно. Canvas хуже для подписей; WebGL избыточен для v1.

### 6. Хостинг: `dist/` + nginx:alpine

Multi-stage: Node собирает, nginx отдаёт. Локально: `npm run dev` / `preview` и `docker compose`. `base` Vite относительный или настраиваемый, чтобы не ломать некорневой путь.

## Risks / Trade-offs

- [Сэмплы пропускают узкую щель] → не меньше 16 внутренних точек + концы; при необходимости позже непрерывный клип отрезка.
- [2D не ловит взгляд сбоку вдоль полки] → явно документировать сечение; вид сверху не SoT.
- [Query string ломается от ручного edit] → валидация и откат к последнему валидному / дефолту.
- [Ретина / масштаб SVG] → viewBox в мм сцены, не пиксели модели.

## Migration Plan

Greenfield. Откат — не выкладывать `dist/` / образ. Совместимости нет.

## Open Questions

- Высота нижней полки от пола как отдельное поле (пересчёт `eyeHeight`) можно добавить без смены алгоритма блика.
- Точный дефолтный `emitAngle` у конкретного углового профиля — 45°, пока нет паспорта профиля.
