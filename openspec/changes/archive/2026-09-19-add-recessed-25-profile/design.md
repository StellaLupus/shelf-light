## Context

См. `proposal.md` (зачем) и дельты в `specs/`. Сейчас `MountType` = `downward` | `radius` | `ell` | `triangle`. Верхняя полка в окклюдерах — один осевой прямоугольник. Окклюдеры умеют только AABB (`segmentHitsRect`, `placeEye`, зона заливки). `led.width` всегда размер источника/тела. Смещение от стены есть только у `downward`.

Координаты как в `openspec/project.md`: +X в комнату, +Y вверх, мм. Низ верхней полки: `y = gap`.

## Goals / Non-Goals

**Goals:**

- Пятый `mount` и флаг разворота в модели ядра, без расчёта блика в React.
- Разрезать верхнюю полку на AABB (кап + две щеки), не вводя полигональные окклюдеры.
- Зафиксировать SKU константами; `led.width` и `profileDrop` не двигают врезку.
- Отдать схеме вырез и сечение канала (`src/viz`), пятый монтаж и тумблер (`src/ui`, `src/state`).
- Обновить монтаж в `openspec/project.md`.

**Non-Goals:**

- Хостинг, новые зависимости, фотометрия, IES.
- Смена алгоритма лучей (полуплоскость + ≥16 сэмплов остаётся).
- Слайдер угла, второй SKU, стоп посадки по внутренней грани бленды.

## Decisions

### 1. Ключи модели: `recessed25` + `facing`

`MountType` дополняется `recessed25`. На `led` — `facing: 'wall' | 'room'`, дефолт `wall`. В URL: `mount=recessed25`, `lface=wall|room`. Нет ключа → `wall`. `corner` → `triangle` как сейчас.

Альтернатива «ещё один угловой у бленды» отвергнута: посадка в пазе, не в кармане.

### 2. Константы SKU

Считать из констант, не из `led.width`:

| Имя | Значение |
|-----|----------|
| Тело с упорами | 40 мм |
| Упор | 2,5 мм на сторону |
| Паз | 35 × 14 мм |
| Свес фланца | 2 мм |
| Молоко | 14 мм вдоль грани |
| Угол молока | 25° от вертикали |
| Окно | 27 мм по X от нижнего края молока до конца выреза |
| Карман ленты | 11,5 мм, только схема |

Проекции молока: Δx = 14 · sin(25°), Δy = 14 · cos(25°). Нижний край на `y = gap` (плоскость низа; фланец 2 мм может торчать ниже). Верх молока ≈ `gap + 14·cos(25°)` — внутри паза.

Отсчёт окна только от нижнего края. Молоко заваливается в окно 27 мм: верх ближе к концу выреза, чем низ.

`offsetFromWall` — до ближнего к стене края тела 40 мм. Паз: `[offset + 2.5, offset + 37.5] × [gap, gap + 14]`.

`facing = wall`: конец выреза и окно к стене, молоко со стороны комнаты. `facing = room`: зеркало по X вокруг середины тела; span 40 мм тот же.

Альтернатива «паз 30,5 мм с витрины» отвергнута: схема 35 + упоры 40. Альтернатива «25° от горизонтали» отвергнута: от вертикали.

### 3. Вырез полки тремя AABB

Не вычитать многоугольник. Окклюдеры верхней полки при `recessed25`:

1. **Cap** — `[0, depth] × [gap + 14, gap + thickness]`, если высота > 0.
2. **Щека к стене** — от `x = 0` до стены паза, `y ∈ [gap, gap + 14]`.
3. **Щека к кромке** — от дальнего края паза до `depth`, тот же Y.

Паз в окклюдеры не входит. Для остальных монтажей `upper` остаётся одним прямоугольником.

Дополнительно: AABB алюминия за молоком (от стенки паза до верхнего края молока, высота паза) и два тонких фланца 2,5 × 2 мм на низе. Филе не оцифровываем. Карман 11,5 мм — не окклюдер и не эмиттер.

`BuiltScene.upper` оставляем bbox для рамки схемы. В `occluders` кладём части, не bbox. Для дырки на схеме — прямоугольник паза.

Альтернатива «оставить целый `upper`» ломает блик: молоко внутри полки, все лучи закрыты. Альтернатива «полигональные окклюдеры» не нужна.

### 4. Эмиттер и сэмплы

Одна `EmitSegment` по молоку. Нормаль в окно (в полость / к концу выреза) так, чтобы точка в заливе под окном была в передней полуплоскости; ε сдвигает сэмпл в воздух паза, не в дерево.

`led.width` для `recessed25` не валидируем как размер (ноль в URL не бракует сцену). Посадка: `offset ≥ 0` и `offset + 40 ≤ upper.depth`. Толщина полки ≥ 14. Стык фланца с блендой не бракуем.

### 5. Модули

- `src/geometry/types.ts` — `MountType`, `facing`, новый `ProfileShape`.
- `src/geometry/scene.ts` / `validate.ts` — сборка и отказ.
- `src/geometry/visibility.ts`, `placeEye.ts`, `litRegion.ts` — без смены примитивов, только другие rect.
- `src/viz` — вырез + полигон канала.
- `src/ui/Controls.tsx` — радио «Врезной 25°», тумблер «к стене / в комнату», скрыть ширину и свес, показать смещение.
- `src/state/params.ts` — `mount`, `lface`.
- Хостинг не трогаем.

## Risks / Trade-offs

- [Сэмпл в дереве → ложный «нет блика»] → вырез обязателен; ε только в воздух полости.
- [AABB алюминия грубее филе] → полуплоскость молока закрывает ход назад; щеки режут ход сквозь плиту. Допустимо для v1.
- [Фланец 2 мм наезжает на бленду у кромки] → не валидируем; пользователь двигает offset. Стоп только `offset + 40 ≤ depth`.
- [Старые ссылки без `lface`] → тихо `wall`.

## Migration Plan

1. Красные тесты SKU, выреза, разворота, валидации; затем ядро.
2. Схема с вырезом, контролы и URL.
3. Обновить `openspec/project.md`.
4. Откат — предыдущий коммит; неизвестный `mount` по-прежнему падает в дефолт.
